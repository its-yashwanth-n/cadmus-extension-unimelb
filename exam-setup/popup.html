Runs once each time you click. Nothing is re-applied afterwards, so you can still change anything by hand.

Quick run

Keyboard shortcut: not set. To change it, go to chrome://extensions/shortcuts in Chrome, or about:addons → ⚙ → Manage Extension Shortcuts in Firefox.

Turning off One-click: right-click the toolbar icon → Options (Chrome), or about:addons → this extension → Options (Firefox).
